# Code of conduct

This project adopts the
[CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md)
as its standard of behaviour. It is an independent project, not a CNCF one, so
the CNCF's own enforcement bodies do not handle reports about it.

## Reporting

To report something in this repository — an issue, pull request, comment or
discussion — use GitHub's **Report content** option in that item's menu. To
report an account, use **Block or report** on its profile. Both go to GitHub,
and neither is visible to the person reported.

The maintainer, [@sharifmshaker](https://github.com/sharifmshaker), enforces
this code in the repository: removing content, locking conversations, and
blocking accounts from the project.

Please do not use the repository's private vulnerability reporting for conduct
issues. It is reserved for security reports; see [SECURITY.md](SECURITY.md).
