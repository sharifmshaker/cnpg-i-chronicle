# Code of conduct

This project follows the
[CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md),
as CloudNativePG and the wider ecosystem do.

Report unacceptable behaviour through GitHub's private reporting on this
repository, or to the CNCF Code of Conduct Committee at <conduct@cncf.io> for
anything involving this project's maintainer.
